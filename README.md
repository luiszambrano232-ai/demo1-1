# Demo Zury's Cafetería

Landing e-commerce estática, responsive y compatible con GitHub Pages.

## Incluye
- Catálogo con filtros.
- Carrito de compras persistente con LocalStorage.
- Cantidad, total estimado, fecha y observaciones.
- Checkout demo por WhatsApp.
- Menú responsive móvil.
- Secciones de marca, horarios, ubicación, RRSS y contacto.

## Datos demo que debes reemplazar antes de producción
Busca en los archivos:
- `56911111111` → número de WhatsApp real.
- `@TU_INSTAGRAM`, `@TU_TIKTOK`, `TU_FACEBOOK` → RRSS reales.
- Productos/precios de `js/app.js` → catálogo real.
- Imágenes remotas → imágenes propias de la cafetería para versión final.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube `index.html`, `css/`, `js/` y `assets/`.
3. En GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Guarda y espera la URL pública.

No requiere PHP ni base de datos para esta demo.


## Imágenes de la demo
Esta versión utiliza imágenes públicas asociadas a Zury's Cafetería únicamente como referencia visual para la propuesta comercial. Para una publicación definitiva se recomienda solicitar al cliente sus fotografías originales y autorización de uso. Los precios, WhatsApp y etiquetas de RRSS son demostrativos.
